# H3 提示词语法

## 四块结构

顺序不要变。模型对开头的权重最高，风格锚点放最前面。

```
[风格锚点]   画质 + 画幅 + 配色 + 材质 + 光线，一句话定死整体观感
[分镜序列]   镜头1 → 镜头2 → 镜头3……每个镜头后挂 [运镜] 标记
[音频指令]   环境声 + 动作音效 + 对白/配乐，说明落在哪一拍
[负面约束]   明确不要出现的东西
```

### 风格锚点写什么

至少覆盖这五项，缺一项模型就自己发挥：

- **画质门类**：电影质感真人实拍 / 平面矢量动画 / 美式硬派漫画 / 3D 渲染
- **画幅**：16:9 / 2.35:1 宽银幕 / 竖屏 9:16
- **配色**：说死具体颜色，「正红、纯黑、纯白三色，无渐变」比「高对比配色」有效十倍
- **材质**：35mm 胶片颗粒 / 网点半调 / 粗黑描边 / 浅景深散景
- **光线**：日落逆光 / 暖光室内 / 顶光硬阴影

**每一段生成都要把这一整块原样重写。**跨段不要写「同上」「保持前一段风格」，
模型看不到前一段。

### 分镜序列写什么

一个镜头一句话，结构是「主体 + 动作 + 环境 + `[运镜]`」。

常用运镜标记：

| 标记 | 效果 |
|---|---|
| `[固定镜头]` | 三脚架不动 |
| `[缓慢推进]` / `[快速推进]` | dolly in |
| `[拉远]` | dolly out，收尾常用 |
| `[横移]` / `[左移]` / `[右移]` | 平移 |
| `[上摇]` / `[下摇]` | tilt |
| `[跟随]` / `[垂直跟拍]` | 跟拍主体 |
| `[手持轻微晃动]` | 纪实感、vlog 感 |
| `[环绕]` | 绕主体转 |
| `[俯拍]` / `[低机位]` | 机位高度 |
| `[逐格硬切]` / `[快速硬切]` | 快闪蒙太奇 |

**不写运镜 = 固定机位死镜头。**这是最常见的翻车原因。

### 音频指令写什么

H3 的音频和画面同一次生成，写清楚三层：

1. **环境底噪** — 风声、雨声、室内安静、街道车流
2. **动作音效** — 脚步、玻璃碎裂、切牌声、马蹄由远及近
3. **人声 / 配乐** — 对白直接写台词；配乐写调性和进出点

例：「风声很大，麦克风被风吹的破音，男声自言自语，远处车流。」

技巧：**用音效标记剪辑点。**「最后一记重音后骤停」比「节奏感强」有用得多。

### 负面约束写什么

高质量 prompt 几乎都以负面约束收尾：

```
不要出现：多余的手指与肢体、变形的面部、画面外的文字与水印、
不必要的镜头抖动、与描述不符的现代物件。
```

## 长 prompt 的分镜表写法

超过 8 秒的片子，用时间码写成场记单，模型的时间分配会准很多：

```
0-4s   —— 主体动作 A，[运镜]，音频：X
4-9s   —— 主体动作 B，[运镜]，音频：Y
9-15s  —— 主体动作 C，[运镜]，音频：Z
```

## 一条 prompt 内塞多少分镜

实测：**15 秒一条 prompt 里塞 8–12 个镜头，H3 能完整还原**，包括结尾的
标题卡文字。这是 H3 相对 2.x 最大的能力跃迁——2.x 是单镜头模型，H3 会自己切。

超过 12 个镜头开始丢镜头，此时应该分段生成。

## 参考素材的分工

一句话：**参考素材负责「是谁、长什么样、什么声音」，prompt 负责「发生什么」。**

| 角色 | 作用 | 数量 |
|---|---|---|
| `first_frame` / `last_frame` | 锁死起止画面，段间接力用 | 各 1 张 |
| `reference_image` | 角色脸、服装、产品外观、UI 样式 | ≤9 |
| `reference_video` | 运镜方式、剪辑节奏、动作 | ≤3 |
| `reference_audio` | 音色、配乐调性 | ≤3 |

不要在 prompt 里花大段文字描述脸——描述不住，传图才行。
