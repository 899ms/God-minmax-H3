# 05 · 单镜头对白特写

| | |
|---|---|
| 类型 | 电影质感真人实拍 · 越肩构图 · 长对白 |
| 验证状态 | **待验证** |
| 生成方式 | 图生视频 / 全能参考（必须传 `reference_audio`） |
| 适用 | 短剧、口播、角色演示 |

## 镜头语言拆解

参考片 23.7 秒**零切点**——整条是一个不动的中近景。

构图是标准越肩：说话者面向镜头略偏一侧，画面另一侧前景放一块虚焦的
听者肩背作为遮挡。这块遮挡很重要，它把「对镜头独白」变成了「对另一个人说话」，
观众的代入方式完全不同。

这类片子考的不是运镜，是**口型、微表情、眼神移动**。所以 prompt 里
描述表演比描述画面重要得多。

## 29 秒版本（2 段 · 15+14）

### 段 A（15s）

```
电影质感真人实拍，中近景固定镜头，85mm 浅景深虚化，暖光室内，
柔和的伦勃朗光打在人物脸上，背景散景成柔和光斑。

一名二十出头的女性面向镜头略偏左说话，栗色长卷发，细银耳环，黑色细吊带；
画面右侧前景是一块虚焦的深色男性肩背，形成越肩构图；
背景是暖光木质室内，右后方一盏烛形壁灯化成柔和光斑 [固定镜头]。

表演：她带着一点戏谑的笑意开口发问，眉毛微挑；说到一半停顿、垂眼；
再抬眼直视镜头，笑意收敛了一点。

台词：「所以告诉我……一个这么有魅力、这么聪明、口才这么好的男人，」

音频：室内很安静，只有壁炉的微弱噼啪声；女声柔和、语速偏慢、带气声，
没有配乐。

不要出现：镜头运动、画面文字与字幕、多余肢体、面部变形、口型与台词不同步。
```

### 段 B（14s）

```
（风格锚点原样重复段 A 第一段）

同一女性、同一服装发型、同一机位与光线，画面完全承接上一段。

表演：她说完后短暂沉默，笑意慢慢收起，视线移开又移回，
最后轻轻吸一口气说出最后一句；说完不再开口，只是看着镜头，
眼神从试探转为落寞 [固定镜头，最后 3 秒极缓推进]。

台词：「……怎么会到现在还是一个人呢？」

音频：同样的室内环境声；女声比上一段更低更慢；最后五秒只剩呼吸与环境声。

不要出现：镜头大幅运动、画面文字与字幕、多余肢体、面部变形、
与上一段不一致的发型服装。
```

## 接缝必须放对位置

两段的接缝落在**一句话说完、人物换气或转开视线的瞬间**。
落在句子中间会听出明显的断裂，这是这类片子唯一致命的失败点。

## 已知坑

- **不传 `reference_audio`，第二段音色基本会变成另一个人。**这是对白片最大的坑。
- 台词写在 prompt 里，H3 会同轨生成对白并对口型。台词长度要匹配时长——
  15 秒塞两句以上会被赶着说完，语速失真。
- 字幕不要让模型生成，一律后期加。prompt 里明确写「不出现画面文字与字幕」。
- 「越肩前景的虚焦肩背」如果不写「虚焦」，模型会画出完整的第二个人，
  构图就散了。
